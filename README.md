# 妙记账本

中文个人记账网页。支持新增、编辑、删除收入/支出，按月汇总、分类环图、每日/每周趋势、搜索筛选、分页及CSV导出。

## 启动

需要 Node.js 20 或更高版本。从仓库根目录执行：

```bash
node server.mjs
```

打开 [本地预览](http://127.0.0.1:4173/)。不需要安装依赖。可用 `PORT=4174 node server.mjs` 指定其他端口。

如果仍在原 BMAD 工作目录中，先进入 `outputs/ledger` 再运行上述命令。

## 测试

```bash
node --test core.test.mjs
```

10项测试覆盖金额精度、日期、分类约束、月份汇总、CSV转义、首次初始化、增删改读写、陈旧快照和损坏/受限存储。

## 数据

数据只保存在当前浏览器的localStorage中，没有账户与云同步。存储键 `qinghe-ledger-v1` 沿用旧名称，以兼容重命名前的数据。首次打开的16笔示例均有标记，可单独清空，新增或编辑后的记录会保留。导出的是当前月份的全部账目，不受表格筛选影响；CSV用于备份和外部查看，本版不支持CSV导入。

共享同一浏览器的多个标签页会自动同步。可用Web Locks时串行保存，同时校验旧快照以避免覆盖；不支持Web Locks的浏览器仍做快照冲突检查。

图表用原生SVG/CSS实现；界面和图标不访问CDN或外部资源。纯计算/存储模块为core.mjs，页面交互为app.mjs。服务器仅监听本机；本次交付是本地网页预览，没有发布到公网。
